## 🏗️ Architecture backend

Je privilégie une architecture modulaire dans laquelle les services orchestrent les composants nécessaires à l'exécution de la logique métier.

```text
Routes
  └── Middlewares
       └── Controllers
            └── Services
                 ├── Rules
                 ├── Repositories
                 ├── Builders
                 ├── Helpers
                 ├── Utils
                 └── Integrations
                      └── Persistance & services externes
```

Les composants interviennent selon les besoins du cas d'utilisation. Les repositories encapsulent les accès aux données, les builders construisent les structures nécessaires, les rules portent les validations métier concernées et les intégrations communiquent avec les services externes.

### Principes d'ingénierie

- **Modularité** — composants organisés autour de responsabilités précises.
- **Cohérence métier** — règles explicites et opérations contrôlées.
- **Sécurité** — validation des entrées et contrôle des accès.
- **Maintenabilité** — code lisible, réutilisable et évolutif.
